# morgen-viewer

The Morgen feed viewer, published with GitHub Pages.

`index.html` is a copy of `viewer.html` from the private Morgen repo. That repo
is the source of truth: change `viewer.html` there first, then copy it here.
The feed, tags and all other data stay in the private repo; the page reads them
through the GitHub token you paste into Settings, which is kept in your browser
and never stored here.

Do not add feed data, the weekly review, or analysis tables to this public
repo. `review/` and `REVIEW.md` are intentionally ignored.
